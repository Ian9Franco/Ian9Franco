## Proyectos destacados

### [MIM — Minecraft Intelligent Manager](https://github.com/Ian9Franco/MIM)

Mi principal proyecto actual: un ecosistema de escritorio y web para gestionar mods y modpacks de Minecraft. Integra desarrollo de aplicaciones, manejo de archivos, diagnóstico y colaboración en la nube.

- **Almacenamiento local:** deduplicación de descargas mediante hashes y búsquedas de archivos con caché.
- **Diagnóstico y recuperación:** análisis de logs de errores de Java, inspección estática de bytecode y reparación de datos NBT de jugadores con copias de seguridad.
- **Desktop y cloud:** aplicación Electron, interfaz web complementaria y colaboración mediante Supabase.
- **Proceso de ingeniería:** decisiones de arquitectura documentadas y controles de CI para tipos, límites arquitectónicos, pruebas, cobertura y builds.

[Web hub](https://mim-hub.vercel.app/) · [Decisiones de arquitectura](https://github.com/Ian9Franco/MIM/tree/main/docs/adr) · [Workflow de CI](https://github.com/Ian9Franco/MIM/blob/main/.github/workflows/ci.yml)

### [Elseframe Comics — Lector interactivo y herramientas creativas](https://github.com/Ian9Franco/ElseframeComics)
