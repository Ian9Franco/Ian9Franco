## Selected projects

### [MIM — Minecraft Intelligent Manager](https://github.com/Ian9Franco/MIM)

My current flagship: a desktop and web ecosystem for managing Minecraft mods and modpacks. It brings together application development, file handling, diagnostics, and cloud collaboration.

- **Local storage:** hash-based download deduplication and cached file lookups.
- **Diagnostics & recovery:** Java crash-log analysis, static bytecode inspection, and NBT player-data repair with backups.
- **Desktop & cloud:** Electron application, companion web interface, and Supabase-backed collaboration.
- **Engineering workflow:** documented architecture decisions and CI checks for types, architecture boundaries, tests, coverage, and builds.

[Web hub](https://mim-hub.vercel.app/) · [Architecture decisions](https://github.com/Ian9Franco/MIM/tree/main/docs/adr) · [CI workflow](https://github.com/Ian9Franco/MIM/blob/main/.github/workflows/ci.yml)
